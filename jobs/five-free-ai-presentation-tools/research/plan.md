# Research plan — five-free-ai-presentation-tools

QUESTION: Which five AI tools genuinely make presentations faster for FREE (as of 2026-09-23),
and where exactly does each free plan stop?
FORMAT: ai-tools (list / top-N), animated treatment (bookends + slides), 40-60s.

Candidate pool (8, to verify down to 5): Gamma, Canva (Magic Design / Canva AI),
Microsoft PowerPoint Designer (free on the web), Google Slides + Gemini,
Napkin AI (text -> visuals), Pitch, Presentations.AI, SlidesGPT / Plus AI.

## Per item — subtopics 1-4 of the product list
1. What it does + documented AI features for presentations (official site / help centre)
2. How to use it — the vendor's own steps (prompt -> deck)
3. Price, free plan ceiling, requirements, platforms, limits (vendor pricing page)
4. Official visuals — product screenshots / demo video / logo (URLs + what each shows)

Agents:
- A: Gamma + Pitch
- B: Canva + Napkin AI
- C: PowerPoint Designer (web, free account) + Google Slides with Gemini (personal accounts)
- D: Presentations.AI + SlidesGPT + Plus AI, AND the "is this list honest" subtopic

## Is this list honest (agent D)
- Ranking basis: none — the reel states each free ceiling, no "best"
- What gets excluded and why (no real free tier, trial-only, watermark-only, card required)
- Independent evidence: hands-on reviews / Reddit complaints about each free tier
- Alternatives + the built-in way (ChatGPT / Claude / Copilot generating a .pptx)
