# Research plan — gemini-google-apps

**Research question:** What Gemini AI features are currently live inside Google's
own productivity apps (Gmail, Docs, Sheets, Drive, and one more if it earns its
place), what do they actually do, how does a user turn them on, and are they free
or paid?

**Format:** ai-tools (list/feature reel, animated treatment — presenter bookends +
stage scenes per feature, ~55s target).

## Subtopics (product/app reel template)

1. **Gemini in Gmail — every documented feature + how to use it.** Official Gmail
   Help Center / Workspace blog / gemini.google.com pages. (Help me write, thread
   summarization, smart reply, etc.)
2. **Gemini in Docs & Sheets — every documented feature + how to use it.** Official
   Docs/Sheets Help Center + Workspace blog. (Help me write/refine in Docs; formula
   generation, "Help me organize", data analysis in Sheets.)
3. **Gemini in Drive (and Slides/Meet if it earns a slot) — every documented
   feature + how to use it.** Official Drive Help Center. ("Ask Drive" / Gemini
   file Q&A, search, summarization.)
4. **Price, plans, requirements, platforms, limitations — vendor-stated.** Google
   One AI Premium vs. Workspace Business/Enterprise add-ons vs. anything now free;
   which of the above features are gated behind which plan; platform availability
   (web/mobile/personal vs. Workspace account).
5. **Official visuals** — screenshots, Workspace blog images, product-page stills,
   official demo/launch videos for each feature above. URLs + what each shows.
6. **Independent evidence** — hands-on reviews, Reddit/forum threads, complaints
   about these features (accuracy, availability, confusion about which plan
   unlocks what).
7. **Alternatives / built-in comparison + is this list honest** — what a viewer
   could use instead (Copilot in Microsoft 365, plain ChatGPT), ranking basis for
   which features made the cut, anything excluded and why.

## Status
Launching subtopics 1-4 first (features + pricing), then 5-7.
