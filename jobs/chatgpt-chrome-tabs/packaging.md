CAPTION: ChatGPT can now click, type and hit submit inside your Chrome tabs, on sites you're signed into.

OpenAI updated its ChatGPT Chrome extension on 15 October. In Work, its agent mode, ChatGPT can send messages, fill out forms, download files and group your tabs.

To set it up:
1. In the ChatGPT desktop app, open Settings, then Computer Use
2. Install the Chrome extension
3. Type @Chrome in a Work chat

By default, ChatGPT asks before it uses each new website. You can allow once, allow that site, or allow all sites. OpenAI labels "Allow for all sites" Elevated Risk, because ChatGPT then stops asking.

While it works, Chrome shows a bar with a Cancel button so you can stop it.

OpenAI says the extension is available on all ChatGPT plans; access to Work may depend on your plan.

CAPTION: ChatGPT can now click, type and submit forms inside your Chrome tabs, on sites where you're already signed in. OpenAI updated its ChatGPT Chrome extension on 15 October 2026.

In Chat, ChatGPT can read across your open tabs.
In Work, its agent mode, it can control your tabs: send messages, fill out forms, download files and group tabs.

How to set it up:
1. Open the ChatGPT desktop app and go to Settings, then Computer Use
2. Install the ChatGPT extension for Chrome
3. Start a Work chat and type @Chrome

By default, ChatGPT asks before it uses each new website. The options are Allow once, Allow for this site, Allow for all sites and Decline. OpenAI marks "Allow for all sites" as Elevated Risk, because ChatGPT then no longer asks for confirmation.

To stop a task, use the Cancel button on the bar Chrome shows while ChatGPT is working.

It also works in Edge, Brave, Opera and Vivaldi. OpenAI says the extension is available on all ChatGPT plans; reports differ on whether free accounts get Work.
