# Research — chatgpt-plugins

Claims ledger + search log. The spine is OpenAI's own public Plugin Directory
(chatgpt.com/plugins and each plugin's listing page, captured on mobile
2026-09-29, text saved in research/listing_text.txt). Vendors' own pages add
launch dates, cost and platform detail. Findings per subtopic: research/findings_*.md.

Ranking basis ("is this list honest"): OUR picks for an everyday iPhone
viewer, not an OpenAI ranking (OpenAI publishes none). Each pick must be
(a) listed in the directory today, (b) usable without a work account,
(c) not US-only, (d) shown doing its job on an official page.

## FEATURES + HOW TO USE

- Canva: create designs from a brief — USED. Generate images, remove backgrounds, resize for social, brand check, bulk create (Enterprise) — CUT (one clear job per pick; bulk is Enterprise).
- Adobe: bulk photo edits — USED; horizontal clip to Reel — USED (it's what our viewer makes); guest start — USED. Express templates, PDFs, CC asset search, data-driven docs — CUT (density).
- Spotify: songs/playlists into chat — USED. Podcasts/audiobooks, Premium custom-vibe playlists — CUT (would need the Free/Premium caveat; the spoken line is true for both).
- Gmail: summarize thread + draft reply — USED. Sending — CUT (sources say web only, paid plans; unverified on iPhone). Action trackers — CUT.
- Malwarebytes: links, numbers, emails, risk level, free — USED. WHOIS/ownership, phone origin — CUT.
- Install: Plugins → Install plugin — USED. @mention — CUT (on screen only, in the listing examples).

## NOT CLAIMED

- Any OpenAI ranking — none exists; these are our picks.
- Gmail SENDS email — sources say web-only on paid plans; never said.
- Adobe works in the iPhone app — Adobe's current page lists desktop + web only; launch said iOS. Not said either way.
- Canva on iPhone — Canva's help shows desktop steps only. Not said.
- Every plugin is free on every plan — plans conflict across sources (taskade vs composio). Only Malwarebytes is called free (vendor's own word). Adobe: "start as a guest" (vendor's own).
- Spotify builds a custom playlist from a vibe — Premium only; not said.
- Custom GPTs retiring (2026-09-11 note, VIA releasebot mirror) and plugins in Voice (2026-09-23) — true and fresh but CUT for momentum; saved for packaging/caption.
- Plugin count — no official figure.
- Instacart in-chat checkout, Apple Music — not in the directory as served to us 2026-09-29; US-only. Excluded.
- Malwarebytes "catches every scam" — it reports reputation/risk; never said it guarantees.
