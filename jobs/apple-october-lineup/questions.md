# Open questions — apple-october-lineup

1. **The editorial angle undercuts the source article's own headline.**
   9to5Mac's "7+ new products in October" piece (the one this request is
   drawn from) reads as a straightforward good-news roundup. This script
   uses it as setup for a twist: the touchscreen MacBook Pro, which several
   outlets *did* list as part of the same October/late-2026 wave as
   recently as a few months ago, has since been reported (by the same
   ultimate source, Bloomberg's Mark Gurman) as slipping to early 2027 over
   a memory-chip shortage. So the reel ends by telling viewers not to
   expect the one product most of them actually want this month. That's a
   deliberate choice to make the reel more honest than the roundup it's
   based on, not a neutral restatement of it. Happy to make it a
   straight "here's everything coming" list instead if you'd rather match
   the source article's tone.
2. **Facecam is trimmed to the hook + one bridge line + the closing line**
   (~15% of runtime) to stay in the news format's 10-20% facecam band —
   the other 7 beats stay on the actual source screenshots throughout,
   including the mechanism/mechanism line ("held back until AI Siri was
   ready"). If you'd rather have more presenter face time, say so and I'll
   rebalance.
3. Two items 9to5Mac's own list named (HomePod 3, and the base iPad) got
   folded in or cut: HomePod 3 is grouped into one "smart home line resets
   together" beat with the home hub and HomePod mini 2 (they share one
   cause — waiting on AI Siri — so three separate beats would repeat the
   same point three times); the base iPad was cut entirely because multiple
   sources say it may not land until early 2027, which would have
   undercut the reel's own honesty ending if I'd counted it as "October."
