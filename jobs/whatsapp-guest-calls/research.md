## FEATURES + HOW TO USE

Every feature WhatsApp's 14 Oct 2026 post documents:
- Guests join without a WhatsApp account — USED (the hook)
- Free — USED ("no cost")
- No time limit — USED
- End-to-end encrypted — USED
- 1:1 and group calls up to 32 people — USED ("up to 32 people")
- Waiting room; host approves each guest — USED
- Host can remove a guest at any time — USED
- Guests can share their screen — USED
- Guests can react (thumbs up, heart) — USED as "react"; emoji names CUT for momentum
- Guests can raise their hand — USED
- Guests cannot see phone numbers, send messages, or add people — USED
- Only WhatsApp account holders can create a call link — CUT as a separate line; implied by "Open the Calls tab" (the host is on WhatsApp)
- Guests join from a computer browser — USED (the catch / payoff)
- Calendar integrations for Google Calendar and Outlook, later this year, via a plugin — USED as one attributed line; plugin install steps CUT (not available yet)

How-to (vendor steps, host side): Calls tab -> "+" icon -> create call link -> share it.
How-to (guest side): open the link in a computer browser -> enter your name -> wait to be admitted.
USED: both, compressed to "Open the Calls tab, tap the plus, and create a call link" and "they type a name and wait".
