# Open questions — 5-chatgpt-features

1. **The five picks.** Voice (Live), Tasks, Memory, Data analysis, Projects — all
   verified live and correctly named as of Sept 2026. Three real candidates were cut:
   Custom Instructions (classic pick, but two personalization-settings items back to
   back felt repetitive — cut for visual variety, not because it's weak), Custom GPTs
   (creation is frozen ahead of a Dec 11, 2026 retirement — would be stale advice),
   and Canvas (retired May 28, 2026, replaced by writing blocks/code blocks — naming
   "Canvas" as current UI would be wrong). Happy to swap Custom Instructions back in for
   one of the five if you'd rather have it than, say, Data analysis.

2. **Order.** Currently Voice, Tasks, Memory, Data analysis, Projects — the hook's
   150-million-a-week stat is about Voice, so Voice leads to pay that off immediately
   (this also doubles as the CONFIRMATION BEAT — the first visual is the actual Voice UI).
   Projects closes since it's the most "pulls everything together" item.

3. **The CTA.** I did NOT use a comment-for-DM gate. Per the constitution, the CTA
   should be the ask the story earns — and since every feature's menu path is shown ON
   SCREEN in the video itself (nothing is being withheld for a DM), gating it behind a
   comment felt dishonest. I used "Save this, then open Settings, and let them run
   without you" instead — a save + action CTA. Let me know if you'd rather do a
   comment-keyword DM (I'd set up `jobs/5-chatgpt-features/giveaway.md` for that).

4. **Two checker notes accepted deliberately, same as five-free-ai-tools:**
   - BRIDGES at 8%: each feature is a separate item; the spine is "already in your
     account, sitting unused," not connective tissue between features.
   - CADENCE: sentences run short and even throughout — deliberate for a fast list, at
     the cost of the "occasionally one long sentence" variety the checker likes to see.

5. **The runtime.** Script is 148 words, which lands the reel somewhere in the
   mid-50s-to-low-60s of seconds depending on final voice pace — a little over the
   ai-tools format's measured 40-60s band, but that band is advisory (not one of the
   three blocking rules), and the extra few seconds is five genuinely distinct, sourced
   features rather than padding. Will confirm the exact number once the VO is generated.

6. **Data analysis naming.** OpenAI's own docs aren't fully consistent — the main
   feature page now says just "data analysis," but a more recently updated FAQ page
   still calls it "Advanced Data Analysis" internally. Script uses the current on-screen
   name, "Data analysis."
