# Research plan — 5-chatgpt-features

## Research question

Which five ChatGPT features are (a) real, currently live, correctly named/located in the
UI as of September 2026, and (b) genuinely underused by an "everyday chat box" user — and
what is the accurate, vendor-sourced "how to use it" for each?

Format: `ai-tools` (utility style, list/top-N shape — 5 items, animated treatment).

## Required subtopics (product/app/tool + list template)

Round 1 — breadth, to narrow the candidate list to 5:

1. **Memory & Custom Instructions** — what each does, how they differ, how to enable/edit,
   official docs, any limits (free vs paid).
2. **Projects & Canvas** — what each is, how to use, availability by plan.
3. **Voice Mode & Tasks (scheduled tasks/reminders)** — what each is, how to enable/use,
   availability by plan/platform.
4. **Custom GPTs, Code Interpreter / Advanced Data Analysis, Search, and adoption
   evidence** — what they do, plus independent evidence (surveys, forum threads, articles)
   on which ChatGPT features are actually underused by typical users — this is what
   justifies "you're probably not using this."

Round 2 (after narrowing to 5) — depth for the surviving 5:

5. **Official visuals** for the confirmed 5 — OpenAI help-center screenshots, help.openai.com
   articles, official announcement/blog images, in-app UI labels — URLs + what each shows.
6. **Honesty check** — is the list honest: current names (not deprecated/renamed features),
   correct plan-gating (free vs Plus/Pro), anything excluded and why.

## Notes

- OpenAI ships changes fast; verify every feature is still live/named this way as of
  Sept 2026, not a training-data memory of an older UI.
- Distinguish free-tier vs Plus/Pro-gated features explicitly — a script claiming a
  Plus-only feature is "just sitting there unused" for a free user would be wrong.
