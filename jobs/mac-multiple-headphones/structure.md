# Structure — mac-multiple-headphones (v2, feature-led)

## STORY ENGINE (framework §4A)

A Mac user who wants to share one movie on two pairs of headphones discovers a
free menu-bar app that does it in four clicks — with a volume, battery and
master control for every pair — which matters because macOS's own route
takes the volume keys away.

## SHAPE (S17)

Product tutorial. v1 was a problem → workaround → app arc and under-served the
app itself (user review 2026-09-17: "we hardly talk any features"). v2 leads with
the result, then how to use it, then each feature as something the viewer can
DO, then Apple's route as context, then the honest catch.

## PROMISE (S2)

One movie, two pairs of headphones, one Mac — and exactly how to set it up.

## OPEN LOOP (S10)

Planted: "It takes a free app called PairPods." (what does it do, how?)
Paid off: the how-to steps and features; the ending returns to "free" with the
requirement and where the link is.

## WHAT -> WHY -> SO WHAT (S7)

WHAT: per-device volume, battery, sample rate, master crown, reconnect timer.
WHY: every pair of headphones is different and Bluetooth drops.
SO WHAT: "your friend can listen louder than you"; a drop-out doesn't end the movie.

## WHAT WAS CUT (S11, S21)

- Launch at Login, Automatic Updates — settings, not reasons to download.
- Homebrew install — link is in the pinned comment.
- HomePod — shown in developer screenshots but not claimed in text.
- Drift correction detail of Audio MIDI Setup — too technical.
