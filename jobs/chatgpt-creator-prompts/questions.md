# Open questions — chatgpt-creator-prompts

1. **Angle.** Not "10 magic prompts", but five prompts in a creator's workflow order (voice,
   ideas, hooks, script, repurpose), tied together by one idea: each one starts with something
   only you have. The hook calls out "write me a viral script" prompts. OK?

2. **CTA.** "Save it for the next time you open ChatGPT." A save fits a prompt toolkit. The alternative
   is a comment keyword (e.g. PROMPTS) with the five full prompts sent in a DM, but the photo
   prompts reel used exactly that last week.

3. **Sources on screen.** The prompts are shown as they appear on the publishers' own pages
   (OpenAI Academy, Descript, Sprout Social), captured on mobile. OpenAI's prompt table clips
   on mobile, so that one is a desktop grab, cropped and zoomed. Credits stay off.

4. **Treatment.** Presenter in the corner circle on the hook and end card only, one
   ElevenLabs voice track, music bed on, captions on.
