# Research plan — ios-27-2-beta-3

QUESTION: What is genuinely NEW in iOS 27.2 developer beta 3 (seeded 2026-10-05, build 24B5099f) versus beta 2, and what matters to an ordinary iPhone owner?
FORMAT: news

1. PRIMARY — Apple's seed (developer release notes, build number, date); exact wording.  -> findings_primary.md
2. INDEPENDENT CONFIRMATION — every beta-3 change confirmed by 2+ outlets that did not copy each other (MacRumors, 9to5Mac, AppleInsider, iClarified, X creators). Record VIA.  -> findings_changes.md
3. CONTEXT — what beta 1 and beta 2 added, what 27.2 is (27.1 = Duo-only), expected release timing.  -> findings_context.md
4. REACTION — testers, forums (MacRumors forum thread, Reddit r/iOSBeta), bugs fixed / still broken.  -> findings_reaction.md
5. CONTRADICT — search for anything claimed "new in beta 3" that was actually in beta 1/2, or not present. (folded into 2 and 4)
6. OFFICIAL VISUALS — what can be shown: iOS 27 Simulator on this Mac (does it have 27.2 b3? likely 27.0 only — check), outlet screenshots, Apple pages.  -> findings_visuals.md
