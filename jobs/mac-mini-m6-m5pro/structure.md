# Structure — mac-mini-m6-m5pro

Written BEFORE the first sentence. Framework:
`styles/shortform-script-framework.md` (S17 shapes; S25 standard).

## SHAPE (S17)

**News.** Apple made an announcement, but the announcement is not the
story — the story is the tension underneath it: the box has quietly become
50% more expensive in a single year while also getting a genuine spec jump.
News shape fits because there is a real consequence (your money buys less
mini than it used to, but the mini itself is better) rather than a list of
features with no throughline.

## PROMISE (S2)

You'll know exactly why the Mac mini costs more now, and exactly what you
get in return for that money — so you can decide if the new one is actually
worth it or if you're just paying for a memory shortage.

## OPEN LOOP (S10)

Planted: the hook states the price jump as a bare, unexplained fact ("the
Mac mini just got $300 more expensive — twice this year") without saying
why yet.
Paid off: the memory-shortage explanation lands right after (beat 2), and
the ending returns to the tension by weighing the price against the actual
spec gain ("more expensive than it's ever been — also more capable than
it's ever been"), closing the loop the hook opened rather than just listing
more facts.

## WHAT -> WHY -> SO WHAT (S7)

WHAT: Apple raised the Mac mini's price twice in 2026 while shipping the
new M6 and M5 Pro chips.
WHY: A global memory (DRAM/RAM) shortage is pushing component costs up
across the industry, and Apple passed that straight to buyers instead of
absorbing it.
SO WHAT: If you're mini-shopping, you're not paying more for the same
machine — you're paying more AND getting a real performance jump (faster
AI, faster graphics, more memory headroom on the Pro tier) — but the base
config's storage (256GB) hasn't grown to match the higher price, so the
value math isn't as clean as the chip numbers alone suggest.

## WHAT WAS CUT (S11, S21)

- Genlock/USB-C camera-sync — real, pro-niche, no viewer-relevant hook;
  would cost a beat with no payoff for a general audience.
- Wi-Fi 7 / Bluetooth 6 / N1 chip, recycled-materials figures — true but
  routine spec-sheet filler that every Apple product ships with; doesn't
  change the buying decision.
- Per-app benchmark claims (Excel, Blender, Affinity, Cyberpunk 2077) —
  redundant with the headline AI/graphics/CPU multipliers already used;
  including both reads as a spec dump.
- Education pricing ($799/$1,599) — a real discount but a narrow audience;
  the standard prices carry the story.
- 1TB storage upgrade price (+$500) — strengthens the "value math" point
  but the base 256GB-at-$899 fact alone already makes it without a second
  number needing its own beat.
