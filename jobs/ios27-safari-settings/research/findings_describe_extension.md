## Name / what
- https://support.apple.com/en-us/149076 — "Describe an Extension lets you create a custom extension using natural language to adjust your view of a website's content or formatting"
- Newsroom 2026-06-08 https://www.apple.com/newsroom/2026/06/apple-intelligence-brings-powerful-ai-capabilities-into-everyday-experiences/ — "users can create custom Safari extensions simply by describing what they want ... like adding a button to save and rate recipes a user has tried."

## Steps (Apple https://support.apple.com/guide/iphone/get-extensions-iphab0432bf6/27/ios/27)
- "Tap [Page Menu], then tap Describe Extension." Page Menu is "on the left side of the search field".
- "Enter a description of what you want to create, or select one of the suggested categories."
- "Safari checks the App Store to see if a matching extension already exists." ... "if there are no results, tap Create."
- "tap Try to try it out" ... "tap [checkmark] to save it."
- Tom's Guide: "Under the same menu as the alert tool".

## Categories (Apple images): Boost Productivity, Improve Focus, Get Creative, Design & Develop, "Describe something else…"
## Examples: Apple = Recipe Keeper ("Save and track cooking recipes..."). Tom's Guide only = reading-time badge, grayscale, block distracting elements.
