# Open questions — claude-memory-everywhere

## 1. CTA: none. Confirm?

`news` format makes a CTA optional (G24 only requires one for `top5` /
`ai-tools` / `comparison`). `new_job.py` scaffolded `cta_keyword: CLAUDE`, and
the last reel (claude-eating-tokens) ended on a COMMENT CLAUDE keyword card.

**My call: no CTA.** This reel is reporting an announcement, not recommending
tools we can DM you. There is nothing to deliver — every fact is on a public
page we already credit on screen. A comment-gate here would be asking for
engagement without offering anything, which is exactly the "earned CTA" line in
the framework (§6, §L). It also means we do not repeat the previous reel's
closing treatment.

Say the word and I will add one.

## 2. The hook says "Claude keeps a file on you."

That is literally true — Anthropic's own screenshot shows a **Profile** file
and a **Topics** list of files, and the post says "Everything Claude remembers
is in a list of files under Topics." The line is written to sound like
surveillance for about a second and then be defused by the next line, which is
the actual news: you can open, edit and delete them.

**Flagging it because it is a register decision, not a factual one.** We are a
publication, and RULES bans manufactured indignation for `news`. I think this
sits on the right side of the line — the tension is real, the announcement
itself is the answer to it, and the reel never implies Anthropic is hiding
anything. If you would rather open flatter ("Claude has been keeping notes on
you, and now it will show you them"), that is a one-word change before approval.

## 3. What I cut, and it is a real omission

The announcement has four named sections. The reel carries three. **"Memory
updates as you chat"** is gone — the beat that said "say your deadline moved to
September, and the next chat already knows."

It was cut at the rehearsal stage for two reasons: it was the only beat that did
not serve the spine (see it → fix it → it follows you → what it refuses), and
those 15 words were the difference between a 79-85s prediction and the 60-80s
band. Runtime is now 73-79s with nothing else touched.

If you would rather keep it, the honest trade is to drop the Team/Enterprise
clause and one facecam beat instead.

## 4. One thing I deliberately did NOT put in the reel

Anthropic's own screenshot shows **"Import memory from other AI providers →
Start import"**. It is a genuinely interesting feature and it would have been an
easy extra beat. It shipped in **March 2026**, not with this announcement, so
including it would have read as new. It is now in the manifest's
`explicitly_NOT_claimed` with the source band banned, so it cannot leak back in
as b-roll.

## 5. The sensitive-topics screenshot shows the switch ON

Anthropic published it that way (it is their mock account). The default is OFF,
and the reel says so out loud — "off by default" lands on a highlighted
sentence from the post, and the switch shot only appears one beat later under
"there's a switch if you want them in", which is the ON state. I am satisfied
that reads correctly, but it is the kind of thing worth one look at the frames.
