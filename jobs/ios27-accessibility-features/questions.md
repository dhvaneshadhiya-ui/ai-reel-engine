# Open questions — ios27-accessibility-features

1. LIST CHANGES vs the BGR article. BGR (May 2026, a preview) listed seven. Ours keeps five
   that Apple's own iOS 27 docs show shipped, and drops:
   - Name Recognition: not new, it shipped in iOS 26 (iOS 27 adds languages, 50+ incl. Hindi).
     It is the only one that works on ANY iPhone. Swap it in for one of the five?
   - FaceTime sign-language interpreter API: not in iOS 27.0, first seen in the 27.2 beta.
   - Sony Access controller: no confirmation since release.
   Also NOT said: the Action button shortcut (one hands-on says it never appeared) and
   Magnifier's high-contrast mode (not in Apple's iOS 27 guide).

   plus UK/Australia for Voice Control). Said once, at the end, instead of after each item.
