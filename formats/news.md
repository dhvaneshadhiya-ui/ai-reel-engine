# Format: news

Tech news, product launches, announcements, "what actually changed". The
default — a sheet with no `format` field is treated as `news`.

**Numbers:** `python3 tools/reel_gates.py --formats`
**Derived from:** `styles/varun-mayya.md` — 11-reel teardown, 2026-07-22.
Runtime and hook set by user rules 2026-08-12.

## Script

Written from `styles/varun-mayya.md` (the look) plus
`styles/varun-script-playbook.md` (the words — hook taxonomy, 6-act skeleton,
connectives, honesty beat, CTA menu). **Load both.**

Budget: **160-215 words -> 60-80s at the measured 2.7 wps** (2026-08-13;
supersedes 220-300, which assumed an unmeasured 3.2 wps).

## What this format is strict about

- The hook opens on the actual tension, surprise or consequence — never a
  generic product announcement (G03).
- Every factual claim gets a receipt on screen; no receipt means a facecam
  line or cut it. We credit sources rather than hedging claims to death
  (G14/G15).
- Rumour-sourced stories are still made — source quality is a framing dial,
  never a gate. Attribute clearly: "Bloomberg reports…".
